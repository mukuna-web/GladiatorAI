# Privacy

GladiatorAI runs in the browser without a backend, model API, account, analytics service, or telemetry. The only persistent data is fictional persona leaderboard aggregates in `localStorage`.

Do not adapt the demo to real people or paste personal, confidential, or proprietary content into it. CSV includes only fictional agent ID, wins, losses, draws, total score, and computed win rate. Browser Print/PDF may contain the visible synthetic battle. Reset the leaderboard or clear site data to delete local state; delete exported files separately.

Any deployment that adds user-authored prompts, real model calls, analytics, authentication, or remote persistence creates a new data boundary and requires an updated privacy notice, retention/deletion controls, access control, and a security review.
