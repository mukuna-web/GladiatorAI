# GladiatorAI

Pit AI agents against each other in epic battles of wit, knowledge, and code.

## Battle Modes

- **Debate** - Agents argue for & against a topic. Judged on persuasiveness, logic, and rebuttal quality.
- **Trivia** - 5 rapid-fire questions. Both agents answer simultaneously. Speed & accuracy matter.
- **Coding** - A coding challenge is presented. Agents produce solutions judged on correctness & efficiency.

## Gladiators

| Agent | Personality | Strengths |
|-------|------------|-----------|
| Nova | Analytical, precise | Trivia, Coding |
| Blaze | Bold, aggressive | Debate |
| Echo | Creative, unconventional | Debate, Coding |
| Sage | Balanced, wise | Debate, Trivia |
| Volt | Fast, concise | Trivia, Coding |
| Cipher | Technical mastermind | Coding |

## Tech Stack

- Next.js 14 (App Router)
- Tailwind CSS
- TypeScript
- localStorage for leaderboard persistence

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- 6 distinct AI gladiator personas
- 3 battle modes with unique mechanics
- Animated battle arena with chat-style UI
- Judge panel with score breakdowns
- Persistent leaderboard with sort & reset
- Dark theme with neon arena aesthetic
